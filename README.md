# applied-linear-algebra

Applied linear algebra, written as [marimo](https://marimo.io) notebooks.

## Setup

```sh
uv sync            # or: pip install -e .
```

## Usage

```sh
uv run marimo edit notebooks/intro.py   # edit interactively
uv run marimo run notebooks/intro.py    # run as an app
```

Notebooks live in `notebooks/` as plain `.py` files.
